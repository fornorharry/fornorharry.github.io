Blender work

A hard-surface model built by hand, then the three items sold in the economy system's shop. The shop items are generated by a Python script, so every model, material and light can be rebuilt or changed from code. Everything is rendered in Cycles.

  1. Model by hand and in code

    The pistol is modelled by hand. The shop items are built with Blender's Python API: lofted blade sections, lathed glass, swept tubes for wraps and arches, faceted gem cuts and noise-shaped rock.

  2. Material & light

    The shop items are fully procedural, with no image textures: hammered gold, brushed steel, velvet, cork, walnut grain and mossy stone. Three-point lighting, reflection cards, and spotlights through haze.

  3. Render & finish

    Cycles on the GPU with OptiX at 640 samples, denoised, then finished in Blender's compositor with bloom, a touch of chromatic aberration and a vignette.

  4. Topology

    Every scene also renders as clay with a wireframe overlay, so the modelling holds up to a close look. Switch any image above to Wireframe to see it.

Teleport-strike guard MovementGuard.luau 
-- Covered more than MaxTravel studs within the window: a teleport, not running.
if flatDistance(root.Position, samples[1].Position) > settings.MaxTravel then
	local state = PlayerState.Get(player)
	if state then
		state.SuspectUntil = now + settings.Lockout
	end
	-- Fresh window, so one teleport counts once.
	history.Samples = { { Time = now, Position = root.Position } }
end

SYSTEM 0216 modules · Rojo project

Data & Saving

Player data that is only ever live on one server, upgrades old saves cleanly, and never writes over a save it can't read.

  • Session locking on atomic UpdateAsync, with stale-lock takeover
  • Versioned schema with step-by-step save migrations
  • Staggered autosave, save on leave, parallel save on shutdown
  • Exponential backoff with jitter and request-budget waits
  • Validated server API; owner-only replication; server-only receipts
  • Mock DataStore that fails on purpose, so every load path is testable in Studio
Session lock check SessionStore.luau 
local owner = meta.LockJobId
if owner and owner ~= SESSION_ID then
	-- Another live server owns this save: write nothing, wait and retry.
	if now - meta.LockTime < session.LockExpiry then
		status = "Locked"
		return nil
	end
	-- Nobody refreshed it for LockExpiry seconds: its server is gone.
	detail = `took over a stale lock from {owner}`
end

SYSTEM 0313 modules · built on System 02

Economy & Monetization

Coins, Gems, a shop, game passes and developer products. Every purchase is checked on the server, and every developer product is granted exactly once.

  • Idempotent ProcessReceipt: a grant and its receipt are saved together
  • Config-driven shop where the client sends only an item id
  • Game passes confirmed with Roblox before any benefit applies
  • VIP coin multiplier through a single Earn function
  • Purchase analytics hook plus Roblox economy events
  • Catalog mistakes fail at startup, never in a player's purchase
Exactly-once grant ReceiptProcessor.luau 
if DataService.HasReceipt(player, receipt.PurchaseId) then
	-- Granted before: only confirm the save.
else
	if not applyGrants(player, product.Grants) then
		return NOT_PROCESSED_YET
	end
	-- Same step as the grant, so every save holds both or neither.
	DataService.RecordReceipt(player, receipt.PurchaseId)
end
if not DataService.SaveNow(player) then
	return NOT_PROCESSED_YET
end
return PURCHASE_GRANTED
